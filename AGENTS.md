# Project instructions

## Credential source of truth

- The private repository `tmcnet-mis/credentials`, specifically `D:\source\credentials\README.md`, is the source of truth for project credentials. Consult its current entries and rotation notes before using or changing credentials.
- Whenever credentials are added, rotated, or corrected in a project, update the corresponding entries in that credential repository in the same task and synchronize outdated copies in affected projects. Do not leave a credential change recorded only in a consuming project or maintain a separate YAML credential inventory.
